# Developers-DNA

A Python-based GitHub profile analyzer that collects and analyzes public GitHub repository data to understand a developer's activity, technologies, and repository statistics.

## What I Learned

This project helped me learn and practically apply:

* **Pandas** for data cleaning, filtering, and analysis
* **NumPy** for numerical operations
* Working with API responses and structured data
* Basic data analysis and visualization concepts

## Features

* Fetches public GitHub repositories
* Analyzes repository languages
* Displays stars
* Processes GitHub data using Pandas
* Performs numerical analysis using NumPy

## Tech Stack

`Python` `GitHub API` `Pandas` `NumPy`

## Run Locally

```bash
git clone https://github.com/harshjxdaun/Developers-DNA.git
cd Developers-DNA
python main.py
```
